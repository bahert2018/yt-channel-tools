Fact Pattern Tool

Fact Pattern Tool is a private, in-house tool used by two YouTube channels, The Fact Pattern and Chasing a Number, to work with their own channels through the YouTube Data API and the YouTube Analytics API.

What it does:

  • Reads each channel's own analytics (views, watch time, retention, traffic sources) to improve future videos.
  • Manages each channel's own videos: titles, descriptions, thumbnails, captions, visibility and scheduling.

It is not offered to the public. Only the channels' own accounts sign in to it, and it never accesses anyone else's channel or data.
