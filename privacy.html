Privacy Policy: Fact Pattern Tool

Last updated: October 25, 2026

Fact Pattern Tool is a private tool used by the YouTube channels The Fact Pattern and Chasing a Number to work with their own channels. This policy explains what data it accesses and what it does with it.

What data the tool accesses

When a channel's own account signs in with Google, the tool can access, through the YouTube Data API and the YouTube Analytics API, only that channel's:

  • channel information (name, ID, subscriber count);
  • video information (titles, descriptions, thumbnails, captions, visibility);
  • analytics reports (views, watch time, audience retention, traffic sources, and revenue reports where available).

How the data is used

The data is used only to analyze the channel's own videos and to manage the channel's own videos (for example, updating a title, a description, a thumbnail or captions). It is not used for advertising, is not sold, and is not shared with anyone.

How the data is stored

Sign-in tokens and downloaded reports are stored only on the channel team's own computer. Nothing is stored on a server run by this tool.

Google API Services

Fact Pattern Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops the tool from accessing the channel; locally stored data can be deleted on request.
